## How to use

1. Clone the original [QMK Firmware repository](https://github.com/qmk/qmk_firmware)
2. Copy the `cygnus_he` folder into `qmk/keyboards/`
3. Build the firmware (for example):
   ```bash
   make cygnus_he:default
   ```
